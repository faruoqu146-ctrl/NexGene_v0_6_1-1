# NexGene v0.6.1

Raven-inspired visual and interaction prototype.

## Run API
Requires Docker Desktop.

    docker compose up

API docs: http://localhost:8000/docs

## Mobile UI
The prototype is in `mobile/index.html`, with `styles.css` and `app.js`.

## Product changes
- Tap-first inputs instead of routine numeric typing
- Guided morning and evening flows
- Expanded lifestyle signals
- Dark, intelligent, understated visual direction
- Today snapshot and baseline insights
- Structured observations through authenticated API

## Validation
This package is source-validated for Python syntax, expected UI/API files, and ZIP integrity.
A full Docker runtime/integration test is not claimed by this package build.
